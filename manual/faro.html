🔒 Regla de Oro de Seguridad — ¡Muy Importante!

La clave maestra privada de tu comunidad (ca_raiz.key) NUNCA debe subirse al servidor VPS.
Esa llave se queda siempre protegida en tu propia computadora. El VPS solo funciona como un repetidor público seguro.

⚡ Personalizador Rápido de Comandos

Ingresá la IP pública de tu VPS contratado. Los comandos de abajo se actualizarán solos para que solo tengas que copiarlos y pegarlos:

Guía Técnica — 7 Pasos
Paso 1: Contratar el Servidor VPS

Podés elegir cualquier empresa en la nube (Hetzner, DigitalOcean, Linode, Vultr, Contabo, etc.). Al momento de crearlo, elegí:

  • Sistema Operativo: Debian 12 (Recomendado) o Ubuntu 22.04/24.04 LTS.
  • Plan: El más económico (1 vCPU y 1 GB de RAM es más que suficiente).
  • Tipo de red: Con dirección IPv4 pública fija.

Anotá la dirección IP y la contraseña o clave SSH que te asignen para el usuario root. Pegala en el personalizador de arriba.

Paso 2: Abrir Puertos en el Panel del Proveedor

En el panel de control web donde contrataste el VPS (sección Firewall o Security Groups), agregá las siguientes reglas entrantes:

PuertoProtocolo¿Para qué sirve?Obligatorio
22TCPAcceso y túnel seguro SSHSí
5230UDP (no TCP)Red Malla privada Nebula (Lighthouse)Sí — Crítico
3531TCPRegistro y recepción de nodosSí

⚠️ Nota: El puerto del panel web (8088 o 8090) NO se abre públicamente a internet. Tu PC se conectará a través de un túnel cifrado SSH.

Paso 3: Subir los Archivos Instaladores al Servidor

Abrí una terminal (PowerShell en Windows o Bash en Linux/Mac) dentro de la carpeta com-org-faro de tu computadora y ejecutá:

ssh root@TU_IP_VPS "mkdir -p /tmp/faro"
scp instalar_debian.sh root@TU_IP_VPS:/tmp/faro/
scp -r bin_linux root@TU_IP_VPS:/tmp/faro/

(Si preferís usar una aplicación gráfica como WinSCP o FileZilla, conectate por SFTP como root y arrastrá instalar_debian.sh y la carpeta bin_linux dentro de /tmp/faro/).

Paso 4: Ejecutar la Instalación en el Servidor

1. Conectate por consola a tu servidor VPS:

ssh root@TU_IP_VPS

2. En la consola del servidor, ejecutá este comando unificado (genera el token e instala todo automáticamente):

cd /tmp/faro && chmod +x instalar_debian.sh && TOKEN=$(openssl rand -hex 32) && echo "=== TU TOKEN ES: $TOKEN ===" && sudo COMARG_ADMIN_TOKEN="$TOKEN" FARO_HOST="TU_IP_VPS" ./instalar_debian.sh

Guardá el TOKEN que se muestra en pantalla y pegalo en el campo superior de esta guía para los siguientes pasos.

Paso 5: Subir los Certificados de la Malla (Lighthouse)

Desde la terminal de tu computadora personal (en la carpeta com-org-faro), subí los certificados generados:

scp faros_emitidos/lighthouse/faro_lighthouse.crt root@TU_IP_VPS:/tmp/
scp faros_emitidos/lighthouse/faro_lighthouse.key root@TU_IP_VPS:/tmp/
scp ca_raiz/ca_raiz.crt root@TU_IP_VPS:/tmp/

Ahora, en la consola de tu servidor VPS, aplicá los certificados e iniciá Nebula:

sudo mkdir -p /etc/nebula
sudo install -m 0644 /tmp/faro_lighthouse.crt /etc/nebula/lighthouse.crt
sudo install -m 0600 /tmp/faro_lighthouse.key /etc/nebula/lighthouse.key
sudo install -m 0644 /tmp/ca_raiz.crt /etc/nebula/ca.crt
rm -f /tmp/faro_lighthouse.* /tmp/ca_raiz.crt
sudo systemctl enable --now comorg-nebula
Paso 6: Abrir el Túnel Seguro desde tu PC

Para administrar los nodos desde el panel web de tu PC sin exponer la seguridad a internet, abrí una terminal en tu computadora y dejá corriendo este comando:

ssh -N -L 8090:localhost:8090 root@TU_IP_VPS

(Mantené abierta esa ventana de terminal mientras quieras aprobar y administrar nodos).

Paso 7: Conectar el Panel Web y Aprobar Nodos

1. En tu navegador, ingresá al panel local: http://localhost:8088

2. En la sección de vinculación o VPS colocá:

  • Host: 127.0.0.1
  • Puerto: 8090
  • Token: (El token guardado en el Paso 4)

¡Listo! Tu Faro en VPS ya está operativo recibiendo conexiones seguras de tu comunidad.

🛠️ Preguntas Frecuentes y Solución de Problemas

SíntomaCausaQué hacer
Los nodos dicen "Handshake timed out" Puerto UDP 5230 bloqueado en el firewall web Asegurate de haber creado la regla con protocolo UDP (no TCP).
Error: "no conectado al canal admin" Túnel SSH no abierto o token incorrecto Revisá que la ventana con ssh -N -L 8090... siga abierta y que el token sea el correcto.
El script estado.sh dice CA: FALTA Es el funcionamiento normal y seguro No te preocupes. En un VPS este mensaje es correcto porque la CA maestra vive en tu PC.
