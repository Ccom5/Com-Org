🔍 Rastreo-Cero
Triaje Forense

Kit forense local de solo lectura para la detección de spyware mercenario de grado estatal (Pegasus, Predator, Candiru, Graphite) en ordenadores Windows, Mac y Linux, teléfonos Android y copias de seguridad de iOS.

  • Modo Read-Only Estricto: No altera datos del sistema ni configuraciones; sólo genera reportes temporales.
  • Zero-Network durante Análisis: Bloqueo absoluto de tráfico de red en la ejecución para impedir fugas.
  • Firmas Curadas & YARA: Indicadores de compromiso STIX y reglas YARA adaptadas para evitar falsas alarmas.

🛡️ Sentinels
Seguridad Móvil

Sistema de defensa activa y almacenamiento cifrado para Android (Grado Activista). Desarrollado para la detección y neutralización de spyware avanzado (e.g., Pegasus), protección contra volcados forenses de RAM (Cellebrite) y camuflaje semántico bajo servicios de sistema.

  • Cifrado Triple Factor (XOR): Clave maestra derivada en RAM desde PIN + BSSID Wi-Fi + TEE chip.
  • Defensa Activa: Anti-Stingray (degradación 2G), detección de emuladores y postura física.
  • Purga Irreversible: Zeroización C++/JNI (explicit_bzero) y borrado en KeyStore ante coacción o debug.

◆ Com Org
Red P2P Soberana

Red de debate libre y organización comunitaria entre pares (P2P), 100% blindada contra la censura. Funciona sobre túneles Nebula sin servidores centrales, sin algoritmos de dopamina y con persistencia estricta en el propio hardware.

  • Identidad de Silicio: Llaves criptográficas derivadas del hardware (Ed25519), sin emails ni contraseñas.
  • Faros a Ciegas (Blind Rendezvous): Coordinación sin almacenamiento de direcciones IP en texto plano.
  • Moderación Física: Aislamiento de nodos infractores sin comité centralizado. Límite de 15.000 caracteres.

Rastreo-Cero · v0.1.4 Binarios compilados · sin Python instalado

Dos plataformas soportadas con paquetes ya compilados. En Linux hay tres vías de instalación según el tipo de equipo: AppImage para escritorio, paquete .tar.gz portable para servidores o sistemas sin FUSE, y binario ELF único con modo consola.

Archivo Plataforma Tamaño Uso
Rastro-cero-instalador.exe Windows 10/11 x64 16,6 MB Instalador por usuario, sin permisos de administrador.
Rastro-cero.exe Windows 10/11 x64 14,8 MB Portable: se abre sin instalar.
Rastro-cero-x86_64.AppImage Linux x86-64 16,3 MB Un archivo, doble clic. Requiere libfuse2.
Rastro-cero-linux-x86_64.tar.gz Linux x86-64 15,4 MB Portable para servidores y equipos sin FUSE.
Rastro-cero Linux x86-64 (ELF) 15,5 MB Binario único con modo consola --cli.

Windows 10 / 11

# Instalador (recomendado): se instala en el perfil del usuario, sin admin
Rastro-cero-instalador.exe
#   Windows mostrará "Windows protegió su PC" -> Más información -> Ejecutar de todas formas
#   (el proyecto no tiene certificado de firma comercial: el aviso es esperado)

# Alternativa portable
Rastro-cero.exe

Linux (x86-64, glibc 2.35 o posterior)

# B.1 AppImage - escritorio, sin instalar nada
chmod +x Rastro-cero-x86_64.AppImage
./Rastro-cero-x86_64.AppImage

#   Falta FUSE 2 (libfuse.so.2)?
sudo apt install libfuse2          # Debian/Ubuntu  (24.04: libfuse2t64)
sudo dnf install fuse-libs         # Fedora
sudo pacman -S fuse2               # Arch
#   O ejecutar sin FUSE:
./Rastro-cero-x86_64.AppImage --appimage-extract-and-run

# B.2 Paquete portable - servidores y equipos sin FUSE
tar -xzf Rastro-cero-linux-x86_64.tar.gz
cd Rastro-cero && chmod +x Rastro-cero && ./Rastro-cero

# B.3 Binario único + modo consola (SSH, sin escritorio)
chmod +x Rastro-cero
./Rastro-cero --cli --lang es --scan-type default --no-menu

Verificación de integridad: sha256sum en Linux y certutil -hashfile ... SHA256 en Windows, contra la huella publicada. El AppImage no empaqueta libX11 ni libfontconfig: se toman del escritorio del equipo.
