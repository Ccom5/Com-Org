🗺️ RedAr: Inteligencia Territorial

Plataforma de descubrimiento, catalogación y triangulación de datos abiertos para cooperativas, agro y organización comunitaria.

¿Por qué nace RedAr?

En la Argentina actual, múltiples organismos e institutos que proveían datos públicos esenciales (INTA, SMN, Vialidad, INAES) sufren desfinanciamiento o discontinuidad en sus APIs oficiales. Depender de un portal centralizado estatal deja desamparadas a cooperativas rurales, productores agrícolas y talleres regionales.

RedAr propone una estrategia de triangulación distribuida: recopilar fuentes satelitales globales que no dependen del gobierno, cruzarlas con feeds RSS de medios provinciales y validar los eventos con reportes vecinales directos.

🌱 Agro y Clima

Focos de calor en tiempo real (NASA FIRMS directo), modelos climáticos abiertos (Open-Meteo) y cuencas hídricas.

🚛 Vialidad y Logística

Estado de rutas nacionales y caminos rurales, puertos y centros de acopio en formato GeoJSON.

⚡ Energía y Servicios

Monitoreo de cooperativas eléctricas locales, cortes de suministro y redes de agua.

Matriz de Credibilidad y Motor de Confianza

Para evitar desinformación o reportes manipulados, el sistema clasifica las observaciones en tres niveles y las cruza automáticamente:

Nivel Origen del Dato Criterio de Validación
Nivel 1: Satélite / Global NASA FIRMS, Open-Meteo, OpenSky, IGN. Lectura directa automatizada sin intermediarios locales.
Nivel 2: Intermedio / Institucional Bolsas de cereales, cooperativas eléctricas, radios locales. Ingesta estructurada de tablas y scrapers RSS.
Nivel 3: Vecinal / Telemetría Sensores IoT (ESP32), productores rurales, asambleas. Requiere coincidencia con al menos 1 fuente de Nivel 1 o 2 para confirmarse.

Uso Rápido del Motor de Descubrimiento 

# 1. Instalar dependencias del motor
cd d:\Sitio\RedAr
pip install -r requirements.txt

# 2. Ejecutar descubrimiento y validación de fuentes CKAN
python main.py

# 3. Exportar catálogo verificado a formato Markdown/Obsidian (listo para RAG en Nexo)
python -m output.exportar_obsidian
