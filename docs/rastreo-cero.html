Triaje Forense · Read-Only · Zero-Network

🔍 Rastreo-Cero (Rastro Cero)

Kit de auditoría forense local de solo lectura para rastreo de vectores de spyware mercenario de grado estatal (Pegasus, Predator, Candiru, Graphite) en ordenadores y copias de seguridad móviles.

01. Propósito y Filosofía Operativa

Rastreo-Cero es una herramienta de ciberdefensa cívica construida sobre el motor de triaje de Zero Breach. Su objetivo primordial es permitir que periodistas, activistas, dirigentes sociales y ciudadanos puedan verificar sus propios dispositivos sin entregar datos sensibles ni confiar en plataformas de diagnóstico basadas en la nube.

🔒 Principio Read-Only estricto: Rastreo-Cero jamás altera configuraciones de sistema, llaves ni archivos auditados. Durante el análisis técnico, las conexiones de red están completamente bloqueadas a nivel de proceso para imposibilitar fugas de datos o alertar a atacantes remotos.

02. Arquitectura Técnica y Capacidades

  • [A]
    Cobertura Multiplataforma: Análisis directo de estaciones de trabajo (Windows 10/11, macOS, distribuciones Linux) e inspección de dispositivos móviles (teléfonos Android vía puente ADB y copias de seguridad de iPhone/iOS).
  • [B]
    Aislamiento de Red durante el Escaneo: Las llamadas de red en tiempo de análisis quedan inhabilitadas. No se efectúan consultas DNS ni subidas de telemetría hacia ningún servidor.
  • [C]
    Indicadores Curados (IoCs / YARA): Cruce exhaustivo con bases de firmas STIX, reglas YARA específicas (Candiru, DevilsTongue) y huellas de dominios atribuidos a consorcios de cibervigilancia (NSO Group, Cytrox/Intellexa).
  • [D]
    Reporte Honesto y No Conclusivo: La herramienta detalla la certeza del hallazgo y las limitaciones del análisis. Un resultado sin indicios detectados se informa con rigurosidad ética, aclarando siempre las áreas que no pudieron ser auditadas.

A. Windows 10 u 11 (x64)

Descargar paquete para Windows

Instalador recomendado. Se instala en el perfil del usuario (%LOCALAPPDATA%\Programs\Rastro Cero), no pide contraseña de administrador, crea acceso en el menú Inicio, ofrece un icono opcional en el escritorio e incluye desinstalador. Antes de copiar un solo archivo muestra el Aviso de instalación con el detalle de lo que el programa hace y no hace. 

# 1. Descargar y ejecutar el instalador
Rastro-cero-instalador.exe

# 2. Windows mostrará "Windows protegió su PC" (SmartScreen)
#    Más información  ->  Ejecutar de todas formas
#    Motivo: el proyecto es anónimo y no tiene certificado de firma comercial.

# 3. Verificar la huella antes de instalar (opcional, recomendado)
certutil -hashfile Rastro-cero-instalador.exe SHA256

Alternativa portable: Rastro-cero.exe funciona sin instalación desde una carpeta de confianza o una unidad extraíble. No crea entradas en el sistema ni deja rastros de instalación; el informe se guarda donde usted indique.

B. Linux (x86-64) — tres opciones de instalación

Descargar paquete para Linux

Requisitos comunes: procesador x86-64, glibc 2.35 o posterior (el binario se compila en Ubuntu 22.04 para conservar ese piso de compatibilidad) y un entorno gráfico con libX11 y libfontconfig, presentes en cualquier escritorio. No es un contenedor: Python, Tk y las listas de indicadores van dentro del paquete, pero las bibliotecas gráficas del sistema se usan del sistema. No requiere permisos de root para ejecutarse.

B.1 — AppImage (opción recomendada para escritorio). Un solo archivo que se abre con doble clic, sin instalar ni desinstalar nada. 

# Permiso de ejecución (solo la primera vez)
chmod +x Rastro-cero-x86_64.AppImage

# Abrir la ventana
./Rastro-cero-x86_64.AppImage

# Comprobar la versión sin abrir la ventana
./Rastro-cero-x86_64.AppImage --version

El AppImage necesita FUSE 2 para montarse. Instalación según distribución: 

# Debian / Ubuntu (hasta 23.10)
sudo apt install libfuse2

# Ubuntu 24.04 y derivadas (paquete renombrado)
sudo apt install libfuse2t64

# Fedora
sudo dnf install fuse-libs

# Arch / Manjaro
sudo pacman -S fuse2

# openSUSE
sudo zypper install fuse

Si no puede o no quiere instalar FUSE, el mismo AppImage funciona en modo extraído: 

# Opción 1: extraer y ejecutar en un paso, sin FUSE
./Rastro-cero-x86_64.AppImage --appimage-extract-and-run

# Opción 2: extraer de forma permanente y ejecutar desde la carpeta
./Rastro-cero-x86_64.AppImage --appimage-extract
./squashfs-root/AppRun

B.2 — Paquete .tar.gz (servidores, equipos sin FUSE, instalaciones mínimas). Es la vía más robusta en Linux: no depende de FUSE ni de ningún montaje. Incluye el binario, la entrada de menú y los iconos. 

# 1. Descomprimir
tar -xzf Rastro-cero-linux-x86_64.tar.gz

# 2. Dar permiso de ejecución y abrir
cd Rastro-cero
chmod +x Rastro-cero
./Rastro-cero

Contenido del paquete: 

Rastro-cero/
├── Rastro-cero            binario ELF x86-64 (sin dependencias de Python)
├── rastro-cero.desktop    entrada de menú
├── rastro-cero.png        icono 256x256
└── rastro-cero.svg        icono vectorial

Para dejarlo integrado en el menú de aplicaciones del usuario (sin root): 

mkdir -p ~/.local/share/applications ~/.local/share/icons/hicolor/256x256/apps
cp rastro-cero.desktop ~/.local/share/applications/
cp rastro-cero.png     ~/.local/share/icons/hicolor/256x256/apps/

# Apuntar la entrada a la ruta real del binario
sed -i "s|^Exec=.*|Exec=$PWD/Rastro-cero|" ~/.local/share/applications/rastro-cero.desktop
update-desktop-database ~/.local/share/applications 2>/dev/null || true

B.3 — Binario ELF único. Si ya dispone del archivo Rastro-cero sin empaquetar, basta con darle permiso y ejecutarlo; es la forma habitual de llevarlo a un servidor por scp. 

chmod +x Rastro-cero
./Rastro-cero

B.4 — Modo consola (sin escritorio gráfico). El mismo binario abre la ventana o funciona como herramienta de línea de comandos. Útil en servidores, sesiones SSH o auditorías desatendidas: 

# Menú interactivo en terminal, en español
./Rastro-cero --cli --lang es

# Escaneo estándar del equipo sin menús
./Rastro-cero --cli --lang es --scan-type default --no-menu

# Tipos de escaneo disponibles:
#   default   revisión estándar del equipo
#   full      revisión completa (más lenta)
#   browser   solo navegadores y perfiles web
#   targeted  rutas concretas indicadas por el usuario
⚠️ Diagnóstico rápido de fallos en Linux:
  • error while loading shared libraries: libfuse.so.2 → falta FUSE 2: instálelo o use --appimage-extract-and-run / el .tar.gz.
  • cannot execute binary file: Exec format error → el equipo no es x86-64 (por ejemplo ARM): no hay binario publicado para esa arquitectura; debe compilarse en el equipo.
  • version 'GLIBC_2.35' not found → distribución más antigua que Ubuntu 22.04: use el paquete portable recompilado o compile localmente.
  • El AppImage no abre tras copiarlo → perdió el permiso de ejecución: chmod +x.
  • Sin ventana en un servidor → no hay servidor gráfico: use el modo --cli.

Verificación de integridad (Windows y Linux). Ningún artefacto está firmado con certificado comercial: el proyecto es anónimo y un certificado exige una identidad legal con nombre. La garantía disponible es la huella SHA-256 publicada junto a cada archivo: 

# Linux
sha256sum Rastro-cero-x86_64.AppImage

# Windows (PowerShell o CMD)
certutil -hashfile Rastro-cero-instalador.exe SHA256

Si la huella no coincide con la publicada, no abra el archivo. Tenga en cuenta que el binario de PyInstaller no es reproducible byte a byte: una recompilación propia dará un SHA-256 distinto, aunque el código sea el mismo. Para auditar el código, se entrega el fuente a quien lo solicite y puede compilarse con python3 build/build_gui_linux.py (Linux) o python build\build_gui_exe.py (Windows).

⚠️ Nota de Emergencia: Si sospechas que eres blanco de un ataque activo de espionaje estatal, preserva el equipo sin reiniciar ni actualizar el sistema operativo y recurre a laboratorios de seguridad cívica independientes antes de manipular evidencias.

04. Uso desde el Código Fuente (sin binarios)

Para auditar o modificar antes de confiar, el proyecto se ejecuta en entorno local con Python 3.9 o posterior y customtkinter:

A. Ventana gráfica: 

# Linux / macOS
sh run-gui.sh
python3 gui/app.py

# Windows
run-gui.cmd

B. Herramienta de línea de comandos: 

python3 -X utf8 scan/zero-breach-toolkit.py --lang es

C. Compilar su propio binario: 

# Linux: requiere python3-tk y pyinstaller; no hay compilación cruzada
python3 build/build_gui_linux.py
sh build/build_appimage.sh --tarball

# Windows
python build\build_gui_exe.py

05. Articulación con Sentinels y Com Org

Dentro del Ecosistema Soberano, Rastreo-Cero y Sentinels forman una pinza de ciberdefensa complementaria:

  • Sentinels: Actúa como guardián residente y activo dentro del dispositivo Android (cifrado XOR en memoria RAM, defensa contra stingrays de telefonía y zeroización inmediata ante coacción física).
  • Rastreo-Cero: Actúa como estación de diagnóstico forense de alta profundidad para auditar desde el exterior sistemas operativos de escritorio, móviles vinculados y backups de iOS.
